# 통합 센서 검증 체크리스트 (Integrated Sensors)

**프로젝트**: STM32G431 Space Balloon Radiosonde
**작업**: LSM6DSV16X + MS5611 통합 테스트
**날짜**: 2026-01-11
**에이전트**: renode-simulation-engineer

---

## 개요

이 체크리스트는 LSM6DSV16X (IMU) + MS5611 (기압계) 센서가 동시에 작동하는지 검증하기 위한 것입니다.
**두 센서가 독립적으로 동작하면서 서로 간섭하지 않는지 반드시 확인해야 합니다.**

## 2. 개별 센서 응답 검증

### 2.1 LSM6DSV16X (I2C1 @ 0x6B)

**테스트 스크립트**: `test_integrated_sensors.resc`

#### WHO_AM_I 레지스터 읽기

**I2C 시퀀스**:
- Write: [0x6B, 0x0F]
- Read: [0x70]

- [ ] WHO_AM_I 응답: 0x70 (정확)
- [ ] I2C1 로그에 읽기 트랜잭션 표시
- [ ] NACK 또는 타임아웃 없음

#### 가속도계 데이터 읽기

**레지스터**: OUTX_L_A ~ OUTZ_H_A (0x28-0x2D, 6 바이트)

**예상 값** (정지 상태, ±2g 범위):
- X축: ~0 LSB (±1000)
- Y축: ~0 LSB (±1000)
- Z축: ~16384 LSB (1g ≈ 16384 LSB/g)

- [ ] Z축 가속도: 15384 ~ 17384 LSB (±1000 허용)
- [ ] X/Y축 가속도: -1000 ~ 1000 LSB
- [ ] Little-endian 바이트 순서 확인 (L, H)

#### 자이로스코프 데이터 읽기

**레지스터**: OUTX_L_G ~ OUTZ_H_G (0x22-0x27, 6 바이트)

**예상 값** (정지 상태, ±250 dps):
- X/Y/Z축: ~0 LSB (±200 허용, 드리프트 고려)

- [ ] 모든 축: -200 ~ 200 LSB
- [ ] 급격한 값 변화 없음 (안정적)

### 2.2 MS5611 (I2C3 @ 0x77)

**테스트 스크립트**: `test_integrated_sensors.resc`

#### Reset 명령

**I2C 시퀀스**:
- Write: [0x77, 0x1E]

- [ ] Reset 명령 전송 확인
- [ ] 응답 없음 (정상)
- [ ] I2C3 로그에 쓰기 트랜잭션 표시

#### PROM 캘리브레이션 읽기

**I2C 시퀀스**:
- Write: [0x77, 0xA2], Read: 2 bytes (C1)
- Write: [0x77, 0xAA], Read: 2 bytes (C5)

**예상 값**:
- C1 (0xA2): 0xA2E0 (41696)
- C2 (0xA4): 0x9188 (37256)
- C5 (0xAA): 0x7D8F (32143)
- C6 (0xAC): 0x6D0F (27919)

- [ ] PROM C1-C6 값이 예상과 일치
- [ ] Big-endian 바이트 순서 (MSB first)
- [ ] CRC-4 검증 가능 (prom[7] 확인)

#### 압력 변환 및 ADC 읽기

**I2C 시퀀스**:
- Write: [0x77, 0x48] (Convert D1, OSR 4096)
- (대기 - 시뮬레이션에서는 즉시 완료)
- Write: [0x77, 0x00], Read: 3 bytes (D1 ADC)

**예상 값** (해수면, 0m):
- D1: ~9,000,000 (압력 ADC)
- D2: ~8,500,000 (온도 ADC)

- [ ] D1 값: 8,500,000 ~ 9,500,000
- [ ] D2 값: 8,000,000 ~ 9,000,000
- [ ] 24-bit 범위 내 (0 ~ 16,777,215)
- [ ] Big-endian 바이트 순서 (MSB first)

## 3. I2C 버스 충돌 검증

### 3.1 동시 통신 테스트

**시나리오**: 펌웨어가 I2C1과 I2C3을 동시에 사용하는 경우

- [ ] I2C1 트랜잭션 중 I2C3 트랜잭션 발생 가능
- [ ] 두 버스 간 간섭 없음 (독립적 버스)
- [ ] 각 버스의 ACK/NACK 신호가 올바름

### 3.2 I2C 오류 검증

**검사 항목**:
- I2C1, I2C3 ErrorInterrupt 발생 여부
- NACK (Not Acknowledge) 오류
- 버스 타임아웃
- Arbitration Lost 오류

- [ ] I2C1 오류 인터럽트 없음
- [ ] I2C3 오류 인터럽트 없음
- [ ] 로그에 "ERROR" 또는 "NACK" 없음
- [ ] 모든 트랜잭션 정상 완료

### 3.3 주소 충돌 검증

**센서 주소**:
- LSM6DSV16X: 0x6B (I2C1)
- MS5611: 0x77 (I2C3)

- [ ] 두 센서가 서로 다른 I2C 버스에 위치
- [ ] 주소가 겹치지 않음 (다른 버스이므로 무관)
- [ ] 각 센서가 자신의 버스에서만 응답

## 4. 센서 데이터 상관성 검증

### 4.1 가속도 vs 정지 상태

**물리적 조건**: 풍선이 상승 중이지만, 가속도는 중력만 작용

**예상 동작**:
- Z축 가속도: 일정하게 ~1g 유지
- X/Y축 가속도: ~0 (기울기 없음)

- [ ] Z축 가속도: 15384 ~ 17384 LSB (60초 동안 일정)
- [ ] X/Y축 가속도: -1000 ~ 1000 LSB
- [ ] 급격한 가속도 변화 없음 (등속 상승)

### 4.2 압력 vs 고도

**시뮬레이션 조건**:
- 상승 속도: 5 m/s
- 시뮬레이션 시간: 60초
- 예상 고도 변화: 0m → 300m

**예상 압력 변화**:
- 초기 (0m): ~1013 mbar
- 최종 (300m): ~978 mbar
- 압력 감소: ~35 mbar (약 -0.12 mbar/m)

- [ ] 초기 압력: 1010 ~ 1016 mbar
- [ ] 최종 압력: 975 ~ 981 mbar
- [ ] 압력이 시간에 따라 감소 (고도 증가)
- [ ] 압력 감소율: 0.5 ~ 0.6 mbar/s (60초 기준)

### 4.3 온도 vs 고도

**대류권 온도 감률**: -6.5°C/km

**예상 온도 변화**:
- 초기 (0m): ~15°C
- 최종 (300m): ~13°C (0.3km × -6.5°C/km ≈ -2°C)

- [ ] 초기 온도: 13 ~ 17°C
- [ ] 최종 온도: 11 ~ 15°C
- [ ] 온도가 약간 감소 (대류권 감률)

### 4.4 센서 융합 가능성

**고도 추정 검증**:
- MS5611 압력 → 기압 고도 계산
- LSM6DSV16X 가속도 → 수직 가속도 적분 (속도 추정)

- [ ] 압력 기반 고도: 0 ~ 300m 범위
- [ ] 가속도 적분 고도 추정 가능 (Z축 일정 → 등속 상승)
- [ ] 두 센서 데이터가 서로 모순되지 않음

## 5. 장시간 시뮬레이션 검증

- [ ] 메모리 오류 없음
- [ ] I2C 통신 계속됨

### 5.2 10분 시뮬레이션 (3km 상승)

**예상 고도**: 5 m/s × 600s = 3000m (3km)

**예상 센서 값**:
- 압력: ~701 mbar (3km ISA 모델)
- 온도: ~-4.5°C
- Z축 가속도: ~16384 LSB (일정)

```renode
start
emulation RunFor "00:10:00"
pause
```

- [ ] 10분 시뮬레이션 안정적 실행
- [ ] 압력: 695 ~ 707 mbar
- [ ] 온도: -6 ~ -3°C
- [ ] Z축 가속도 여전히 ~1g

### 5.3 37분 시뮬레이션 (11km 대류권 경계)

**예상 고도**: 5 m/s × 2200s = 11000m (11km)

**예상 센서 값**:

- 온도: ~-56.5°C (성층권 등온층 시작)
- Z축 가속도: ~16384 LSB (일정)

```renode

```

- [ ] 37분 시뮬레이션 안정적 실행
- [ ] 압력: 220 ~ 232 mbar
- [ ] 온도: -58 ~ -55°C
- [ ] 메모리 누수 없음
- [ ] CPU 부하 안정적

## 6. 성능 및 타이밍 검증

### 6.1 I2C 통신 빈도

**예상 통신 주기**:
- LSM6DSV16X: WHO_AM_I 1회 + 센서 데이터 주기적 읽기
- MS5611: Reset 1회 + PROM 7회 + D1/D2 변환 반복 (10Hz)

- [ ] I2C1 로그에 주기적 트랜잭션 확인
- [ ] I2C3 로그에 10Hz 압력/온도 변환 확인
- [ ] 두 버스의 통신이 겹치지 않거나, 겹쳐도 오류 없음

### 6.2 CPU 부하

**정상 범위**:
- PC 레지스터: 계속 진행
- SP 레지스터: 스택 안정적 (오버플로우 없음)

- [ ] PC가 0x08001E7D 이후 계속 진행
- [ ] SP가 0x20007FA0 부근에서 안정적
- [ ] 무한 루프나 멈춤 없음

### 6.3 시뮬레이션 속도

**Renode 가상 시간**:
- 실제 시간보다 빠르게 실행 (정상)
- 가상 시간은 정확함

- [ ] 60초 시뮬레이션이 실제로 몇 초 이내 완료
- [ ] 가상 시간 60초가 정확히 경과 확인

## 7. 오류 조건 처리

### 7.1 센서 미응답 시나리오

**가정**: DLL이 로드되지 않았거나 센서가 등록 안 됨

- [ ] Renode가 적절한 오류 메시지 표시
- [ ] "Peripheral not found" 또는 유사 메시지
- [ ] 시뮬레이션이 크래시하지 않음

### 7.2 잘못된 I2C 주소 접근

**시나리오**: 펌웨어가 존재하지 않는 I2C 주소로 접근

- [ ] NACK 응답 (정상)
- [ ] I2C ErrorInterrupt 발생 (펌웨어에서 처리)
- [ ] Renode가 경고 로그 출력 (옵션)

### 7.3 DLL 로드 실패

**원인**: DLL 파일이 없거나 경로가 잘못됨

- [ ] Renode가 명확한 오류 메시지 표시
- [ ] "Could not load assembly" 또는 유사 메시지
- [ ] 파일 경로를 확인하도록 안내
