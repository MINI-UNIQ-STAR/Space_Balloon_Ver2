# Renode 시뮬레이션 구현 노트

## 개요

이 문서는 STM32G431CBU6 기반 라디오존데의 Renode 시뮬레이션 구현에 대한 기술적 세부사항을 설명합니다.

## 아키텍처

### 플랫폼 계층

```
┌─────────────────────────────────────┐
│   Firmware (Bare-metal)             │
│   - app.c, sensors.c, etc.          │
└─────────────────────────────────────┘
              ↓ HAL API
┌─────────────────────────────────────┐
│   STM32 HAL Driver                  │
│   - I2C, UART, ADC, Timer, etc.     │
└─────────────────────────────────────┘
              ↓ MMIO
┌─────────────────────────────────────┐
│   Renode Platform (stm32g431.repl)  │
│   - Memory map                      │
│   - Peripheral definitions          │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│   Sensor Models (C# DLL)            │
│   - I2C peripherals (8 sensors)     │
│   - UART devices                    │
└─────────────────────────────────────┘
```

## 구현된 컴포넌트

### 1. 플랫폼 정의 (stm32g431.repl)

**기반**: `platforms/cpus/stm32g4.repl`

**커스터마이징**:
- 메모리 크기 조정 (Flash: 128KB, SRAM: 32KB)
- I2C1, I2C3 추가
- UART1, UART2, UART3 설정
- ADC1 (배터리 전압 모니터링)
- 타이머 (TIM1, TIM8, TIM16)
- DMA 채널
- GPIO 포트 (A, B, C, D, F)

**주요 메모리 맵**:
```
0x08000000 - 0x0801FFFF  Flash (128KB)
0x20000000 - 0x20007FFF  SRAM (32KB)
0x40005400 - 0x400057FF  I2C1
0x40007800 - 0x40007BFF  I2C3
0x40013800 - 0x40013BFF  USART1
0x40004400 - 0x400047FF  USART2
0x40004800 - 0x40004BFF  USART3
```

### 2. I2C 센서 모델 (C# 구현)

#### LSM6DSV16X (lsm6dsv16x_i2c.cs)
- **주소**: 0x6B (I2C1)
- **구현**: 6축 IMU (가속도/자이로)
- **데이터**: 정현파 움직임 시뮬레이션 (Z축 중력 반영)
- **검증**: WHO_AM_I (0x0F -> 0x70) 확인됨

#### MS5611 (ms5611_i2c.cs)
- **주소**: 0x77 (I2C3)
- **구현**: 고정밀 기압계 (성층권 시뮬레이션 0-40km)
- **특징**: ISA(표준 대기) 모델 적용, PROM CRC-4 계산
- **검증**: PROM 읽기 및 ADC 변환 시퀀스 확인됨

#### SHT31 (sht31d_i2c.cs)
- **주소**: 0x44 (I2C3)
- **구현**: 온습도 센서 (16-bit 명령어 지원)
- **특징**: CRC-8 체크섬 계산
- **검증**: 측정 명령 및 상태 레지스터 확인됨

#### CM1107N (cm1107n_i2c.cs) - **[Phase 7 중요 업데이트]**
- **주소**: 0x31 (I2C3)
- **프로토콜**: **UART-over-I2C** (펌웨어 드라이버 일치)
  - 명령: `0x11 0x01 0x01 0xED` (4 bytes)
  - 응답: `0x16 0x05 0x01 ...` (8 bytes)
- **검증**: 펌웨어 드라이버(cm1107n_driver.c)와 프로토콜 일치 확인 및 수정 완료

#### MCP9600 (mcp9600_i2c.cs)
- **주소**: 0x60 (I2C3)
- **구현**: 열전대 온도 센서
- **특징**: Hot/Cold Junction 온도 시뮬레이션

#### GDK101 (gdk101_i2c.cs)
- **주소**: 0x18 (I2C1)
- **구현**: 감마선 센서
- **특징**: 고도에 따른 우주선(Cosmic Ray) 증가 시뮬레이션

#### SEN0321 (sen0321_i2c.cs)
- **주소**: 0x70 (I2C3)
- **구현**: 오존 센서
- **특징**: ByteRegisterCollection 활용

#### MLX90393 (mlx90393_i2c.cs)
- **주소**: 0x0C (I2C1)
- **구현**: 3축 자기장 센서

### 3. UART 센서

#### GPS XA1110 (gps_xa1110.cs)
- **연결**: USART1
- **기능**: NMEA 문장 생성 (GGA, RMC)
- **시뮬레이션**: 위도/경도/고도 변화 패턴

## Renode 특화 고려사항

### 타이밍 시뮬레이션
Renode는 가상 시간을 사용하므로 `emulation RunFor` 명령어로 시간을 제어해야 합니다. 센서의 내부 동작(ADC 변환 시간 등)은 가상 시간을 기준으로 시뮬레이션됩니다.

### 디버깅 전략
```resc
# I2C 통신 상세 로그
logLevel 0 i2c1
logLevel 0 i2c3.cm1107n
```
