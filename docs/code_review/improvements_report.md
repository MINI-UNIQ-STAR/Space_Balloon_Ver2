## 상세 내용

### IMP-01: LoRa32 CSMA/CAD 구현
- **현황**: 현재 LoRa 전송은 5초 간격으로 무조건 전송함. 다른 노드와 충돌 가능성 있음.
- **개선**: SX1276의 CAD (Channel Activity Detection) 기능을 사용하여 채널이 비어있을 때만 전송하도록 로직 추가.
- **위치**: `telemetry_rx_lora32v2.1.ino`

### IMP-02: LoRa32 SD 카드 관리
- **현황**: 부팅 시마다 새 파일을 생성하지만, 디스크가 꽉 찼을 때의 처리가 없음.
- **개선**: 오래된 로그 자동 삭제 또는 순환 버퍼 덮어쓰기 로직 추가.
- **위치**: `telemetry_rx_lora32v2.1.ino`

### IMP-03: HIL I2C Mock 레지스터 맵 확장
- **현황**: `WHO_AM_I` 및 데이터 레지스터만 구현됨. 설정 레지스터(CTRL 등) 접근 시 0 반환.
- **개선**: 주요 설정 레지스터에 대한 Read/Write 상태 저장 로직을 추가하여 드라이버 초기화 검증 범위 확대.
- **위치**: `LSM6DSV16X_mocking.ino` 등 I2C Mock 스케치 전반

### IMP-04: MS5611 Mock ADC 역산
- **현황**: ADC Read 요청 시 고정값 또는 단순 임의값을 반환함.
- **개선**: `mock_temp`, `mock_press` 물리량을 기반으로 MS5611의 보정 공식(D1, D2)을 역산하여 Raw ADC 값을 생성하면, 드라이버가 이를 다시 물리량으로 변환했을 때 정확성을 검증할 수 있음.
- **위치**: `ms5611_mocking.ino`

### IMP-05: XCP 프로토콜 구현
- **현황**: `xcp.c`, `xcp.h`가 스텁(Stub) 상태로 존재함.
- **개선**: ASAM XCP 표준에 맞게 Connect, Upload, Download, DAQ 커맨드 처리 구현. PID 튜닝이나 실시간 변수 관측에 활용 가능.
- **위치**: `Core/Src/xcp.c`

### IMP-06: SIL 드라이버 테스트 경고 수정
- **현황**: 외부 센서 드라이버(ST 공식 드라이버 등)가 임베디드 컴파일러에 최적화되어 있어, MSVC/MinGW 등 PC 컴파일러에서 타입 캐스팅 경고 발생.
- **개선**: `HOST_TEST_MODE` 매크로 등을 활용하여 모의 실험 환경에서의 컴파일 경고 제거.
- **위치**: `Core/Drivers/*` 및 `test/test_drivers`

### IMP-07: MLX90393 미사용 함수 정리
- **현황**: `MLX90393_Transceive` 함수가 내부적으로 정의되어 있으나 실제로는 사용되지 않음. 또한 `ReadReg`의 반환값을 무시하는 경우가 일부 존재.
- **개선**: 미사용 함수 주석 처리 및 모든 레지스터 읽기 함수의 반환값 검사 추가.
- **위치**: `Core/Drivers/mlx90393/mlx90393_driver.c`

### IMP-08: GDK101 초기화 에러 구체화
- **현황**: `GDK101_Init`에서 연결 실패 시 단순히 -1을 반환함.
- **개선**: I2C NACK, ID 불일치 등 실패 원인을 구분하여 반환하도록 개선.
- **위치**: `Core/Drivers/gdk101/gdk101_driver.c`

### IMP-09: CM1107N 읽기 지연 검토
- **현황**: 데이터 시트상 측정 요청 후 지연이 필요할 수 있으나, 현재 코드에서는 `delay(20)`이 주석 처리되어 있음.
- **개선**: 실제 하드웨어 테스트를 통해 안정적인 읽기를 위한 지연 시간이 필요한지 검증 후 복구.
- **위치**: `Core/Drivers/cm1107n/cm1107n_driver.c`

### IMP-10: Minmea RMC 파싱 최적화
- **현황**: 모든 NMEA 문장을 파싱하고 있으나, 필수적인 시간/위치 정보는 RMC만으로 충분할 수 있음.
- **개선**: 리소스 절약을 위해 RMC 파싱 위주로 구성을 최적화하거나 불필요한 문장 무시 설정.
- **위치**: `Core/Src/sensors.c` (GPS 콜백)

### IMP-11: LSM6DSV16X 컴파일러 호환성
- **현황**: ST 공식 드라이버가 임베디드 컴파일러(GCC/ARM)에 최적화되어 있어 PC 시뮬레이션(MSVC) 시 경고 발생.
- **개선**: `mock_hal.h` 등에서 타입 매크로를 조정하거나 경고 억제 옵션 적용.
- **위치**: `Core/Drivers/lsm6dsv16x/`
