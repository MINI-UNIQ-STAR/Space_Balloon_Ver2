# Renode C# Models (Sensors & Peripherals) 코드 리뷰

| 항목 | 내용 |
|------|------|
| **위치** | `RENODE_TEST(HIL)/renode/sensors/`, `.../peripherals/` |
| **파일 수** | 14개 센서 모델, 3개 핵심 페리페럴 모델 |
| **언어** | C# (.NET 6.0) |

## 1. 핵심 페리페럴 모델 (STM32G4)

| 모듈 | 파일 | 주요 구현 내용 |
|------|------|------|
| **RCC** | `STM32G4_RCC.cs` | 클럭 활성화 레지스터(AHB/APB) 모사, 펌웨어 부팅 블로킹 해결 |
| **FLASH** | `STM32G4_FLASH.cs` | 플래시 제어 레지스터(ACR) 및 Wait State 모사 |
| **PWR** | `STM32G4_PWR.cs` | 전원 제어 및 상태 레지스터 모사 |

### 평가
- ✅ **안정성**: Memory Mapped 방식과 C# 로직을 병행하여 펌웨어의 초기 HW 설정을 완벽히 통과시킴.
- ✅ **로깅**: 레지스터 쓰기 시 상세 로그를 남겨 디버깅 편의성 제공.

## 2. 센서 모델 (II2CPeripheral / IUARTPeripheral)

| 센서 타입 | 주요 모델 | 특징 |
|------|------|------|
| **I2C 센서** | MS5611, SHT31, LSM6DSV16X, CM1107N 등 | 레지스터 기반 Read/Write 프로토콜 완벽 구현 |
| **UART 센서** | GPS XA1110, PMS3003 | NMEA 문장 및 바이너리 프레임 스트리밍 시뮬레이션 |
| **복합 모델** | MS5611 | PROM 캘리브레이션 데이터 및 ISA 대기 모델 기반 ADC 역산 구현 |
