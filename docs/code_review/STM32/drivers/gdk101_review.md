# GDK101 방사선 센서 드라이버 코드 리뷰

| 항목 | 내용 |
|------|------|
| **센서** | GDK101 γ-Ray 센서 |
| **인터페이스** | I2C (0x18) |
| **파일 수** | 2 (.c, .h) |
| **코드 라인** | 54 + 40 = 94줄 |

## 구조

| 함수 | 설명 |
|------|------|
| `GDK101_Init()` | 상태 읽기로 연결 확인 |
| `GDK101_Reset()` | 리셋 명령 |
| `GDK101_Read_10Min_Avg()` | 10분 평균 방사선량 |
| `GDK101_Read_1Min_Avg()` | 1분 평균 방사선량 |
| `GDK101_Read_Status()` | 상태/진동 감지 |

## 평가

| 항목 | 점수 | 비고 |
|------|------|------|
| **추상화** | ⭐⭐⭐⭐⭐ | read_reg/write_reg 함수 포인터 |
| **에러 처리** | ⭐⭐⭐⭐ | -1 반환 |

- ✅ 레지스터 맵 상수화 (`GDK101_REG_*`)
