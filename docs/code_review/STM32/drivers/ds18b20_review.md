# DS18B20 온도 센서 드라이버 코드 리뷰

| 항목 | 내용 |
|------|------|
| **센서** | Dallas DS18B20 디지털 온도 |
| **인터페이스** | 1-Wire |
| **파일 수** | **13개** (전체 스택) |
| **구성** | 드라이버 래퍼 + 1-Wire 프로토콜 |

## 파일 구조

| 레이어 | 파일 | 역할 |
|--------|------|------|
| **Driver** | `ds18b20_driver.c/h` | 래퍼 (22줄) |
| **Library** | `ds18b20.c/h` | 온도 변환 |
| **Protocol** | `ownet.c`, `owlink.c` | 1-Wire |
| **HAL** | `owhal.h`, `owhal_mock.c` | 플랫폼 추상화 |
| **CRC** | `crcutil.c/h` | CRC 연산 |
