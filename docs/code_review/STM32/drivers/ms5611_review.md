# MS5611 기압계 드라이버 코드 리뷰

| 항목 | 내용 |
|------|------|
| **센서** | MS5611 고해상도 기압계 |
| **인터페이스** | I2C (0x77) |
| **파일 수** | 2 (.c, .h) |
| **코드 라인** | 186줄 |

## 구조

| 함수 | 설명 |
|------|------|
| `MS5611_Init()` | PROM 읽기, CRC4 검증 |
| `MS5611_Read_PT()` | 비차단 상태머신 읽기 |

## 상태 머신
```
S_IDLE_START_D1 → S_WAIT_D1 (10ms) → S_START_D2 → S_WAIT_D2 (10ms) → 완료
```
