# SHT31 온습도 센서 드라이버 코드 리뷰

| 항목 | 내용 |
|------|------|
| **센서** | SHT31-D 온습도 센서 |
| **인터페이스** | I2C (0x44) |
| **코드 라인** | 140줄 |

## 구조

| 함수 | 설명 |
|------|------|
| `SHT31_Init()` | SW 리셋 |
| `SHT31_ReadTempHum()` | 비차단 상태머신 읽기 |
| `SHT31_SetHeater()` | 히터 제어 (결로 방지) |

## 상태 머신
```
SHT_IDLE → SHT_WAIT (15ms) → 완료
```

## 평가

| 항목 | 점수 | 비고 |
|------|------|------|
| **CRC** | ⭐⭐⭐⭐⭐ | CRC8 구현 (Poly 0x31) |
| **비차단** | ⭐⭐⭐⭐⭐ | 상태 머신 |
| **문서화** | ⭐⭐⭐⭐⭐ | 16비트 명령 처리 설명 |
| **기능** | ⭐⭐⭐⭐⭐ | 히터 제어 |

## 장점
- ✅ CRC8 온/습도 모두 검증
- ✅ 결로 방지 히터 API
- ✅ 상세한 프로토콜 주석

## 종합: ⭐⭐⭐⭐⭐ (5/5)
