## 구조

| 함수 | 설명 |
|------|------|
| `PPS_Init()` | 상태 변수 초기화 |
| `PPS_GetSlot()` | 현재 20ms 슬롯 번호 (0-49) 계산 |
| `PPS_IsSynced()` | 동기화 유지 상태 확인 (1.1초 타임아웃) |
| `PPS_GetTimeSinceLastPulse_us()` | 마지막 펄스 이후 경과 시간 (us) |
| `HAL_GPIO_EXTI_Callback()` | EXTI4 인터럽트 핸들러 (PPS 상승 엣지) |

## 핵심 기능

1. **시간 동기화**: GPS 1PPS 신호의 상승 엣지를 기준으로 시스템 시간을 동기화 (±100ns 정밀도).
2. **슬롯 관리**: 1초를 50개의 20ms 슬롯으로 분할하여 50Hz 텔레메트리 전송 시점 결정.
3. **타임아웃 감지**: 마지막 PPS 수신 후 1.1초 경과 시 동기화 손실(`pps_synced = false`) 판정.
4. **인터럽트 기반**: EXTI4 (PB4) 인터럽트를 사용하여 지연 없는 엣지 캡처.
5. **폴백 메커니즘**: PPS 신호 유실 시 내부 `HAL_GetTick()`(DWT/SysTick) 기반 슬롯 계산으로 자동 전환하여 루프 연속성 유지.
