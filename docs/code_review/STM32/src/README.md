## 핵심 분석 포인트

1.  **계층화된 아키텍처**: HAL -> BSP -> Service -> Application으로 이어지는 명확한 레이어 분리를 통해 유지보수성과 이식성을 극대화했습니다.
2.  **견고한 안전 설계**: FDIR 모듈을 중심으로 센서 타임아웃 처리, 저온/저전압 보호, 고도 데이터 페일오버 등 우주 풍선 미션의 극한 환경에 대비한 안전 로직이 전반에 걸쳐 구현되었습니다.
3.  **실시간성 보장**: 50Hz(20ms) 메인 루프 내에서 비차단(Non-blocking) 방식의 상태머신 설계를 적용하여 정밀한 제어 주기를 유지합니다.
4.  **검증 가능성**: `HOST_TEST_MODE` 및 Mock 기능을 통해 하드웨어 없이도 로직 검증이 가능하도록 설계되었습니다.
