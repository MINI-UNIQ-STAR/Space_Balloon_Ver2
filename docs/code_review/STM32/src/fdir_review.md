## 상태 머신

```
HEALTHY → (타임아웃) → WARNING → (리셋) → RECOVERY
                                        ↓ (실패)
                                PERMANENT_FAILURE
```

| 기능 | 함수 |
|------|------|
| **초기화** | `FDIR_Init()` |

| **상태 업데이트** | `FDIR_Update()` |
| **범위 검증** | `ValidateRange_Baro/GPS/Temp()` |
