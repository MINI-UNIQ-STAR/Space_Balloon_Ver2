## 구조

| 함수 | 설명 |
|------|------|
| `App_Init()` | BSP, 센서, PID, 칼만, XCP, 텔레메트리, 액추에이터, FDIR, PPS 초기화 |
| `App_Loop()` | 50Hz 메인 루프 (13단계 처리) |
| `App_IsLowVoltageMode()` | 저전압 모드 상태 조회 |

## 핵심 기능

1. **센서 데이터 수집** (50Hz, 11개 센서)
2. **FDIR 온도 기반 보호** (저온 센서 비활성화)
3. **SHT31 히터 제어** (결로 방지, 0~2°C 히스테리시스)
4. **GPS 고도 추적 및 연속성 검증**
5. **IMU SFLP 자세 추정** (쿼터니언 → Euler 변환)
6. **기압 고도 계산** (101325Pa 기준)
7. **칼만 필터 고도 융합** (예측 + 업데이트 + 발산 검사)
8. **저전압 보호** (< 2.7V 히터 차단, > 2.9V 해제)
9. **PID 히터 제어** (배터리 60% 제한, 보드 100%)
10. **액추에이터 출력** (PWM 듀티 사이클)
11. **FDIR 상태 플래그 생성** (텔레메트리용)
12. **텔레메트리 전송** (UART3, CRC16)
13. **FDIR 타임아웃 체크 및 복구**
