## 구조

| 함수 | 설명 |
|------|------|
| `App_Init()` | PID/Kalman 초기화, 센서 초기화, FDIR 초기화 |
| `App_Loop()` | 50Hz 메인 루프 |

## 핵심 기능

1. **센서 데이터 수집** (50Hz)
2. **칼만 필터 고도 융합**
3. **PID 히터 제어** (배터리/보드)
4. **쿼터니언 → 오일러 변환**
5. **텔레메트리 프레임 생성**
6. **FDIR 마스킹** (실패 센서 0xFFFF)
