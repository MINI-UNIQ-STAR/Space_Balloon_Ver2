# 코드 리뷰 + 개발 병렬 워크플로우

이 워크플로우는 개발과 동시에 코드 품질 검증을 수행합니다.

---

## ⚠️ 필수 사전 단계 (반드시 수행)

### Step 0: 정보 확인 및 질문

**시작 전 반드시 확인해야 할 정보:**

| 필수 정보 | 확인 여부 | 부족 시 질문 예시 |
|-----------|----------|------------------|
| 개발할 기능 명세 | [ ] | "어떤 기능을 개발해야 하나요?" |
| 리뷰 기준/표준 | [ ] | "MISRA-C, CERT-CPP 등 따라야 할 코딩 표준이 있나요?" |
| 기존 코드베이스 | [ ] | "기존 코드의 위치와 구조를 알려주세요" |
| 품질 요구사항 | [ ] | "특별히 중요한 품질 요구사항이 있나요? (안전성, 성능 등)" |
| 테스트 요구사항 | [ ] | "단위 테스트가 필요한가요? 커버리지 기준은?" |

> [!IMPORTANT]
> **정보가 부족하면 절대 추측하지 말고 사용자에게 질문하세요!**
> 리뷰 기준이 명확하지 않으면 효과적인 코드 리뷰가 불가능합니다.

**질문 템플릿:**
```
코드 리뷰+개발을 시작하기 전에 몇 가지 확인이 필요합니다:

1. [누락된 정보 1]?
2. [누락된 정보 2]?
3. [누락된 정보 3]?

위 정보를 제공해 주시면 계획을 수립하겠습니다.
```

---

### Step 1: 계획 수립 (implementation_plan.md 작성)

> [!CAUTION]
> **계획 없이 코딩을 시작하지 마세요!**
> 반드시 `implementation_plan.md`를 작성하고 사용자 승인을 받은 후 진행합니다.

**계획서에 포함할 내용:**

```markdown
# 코드 리뷰+개발 계획

## 1. 개요
- 기능: [개발할 기능 설명]
- 범위: [수정할 파일 및 범위]

## 2. 리뷰 기준

| 카테고리 | 기준 | 우선순위 |
|---------|------|---------|
| 안전성 | MISRA-C 2023 | 필수 |
| 메모리 | 버퍼 오버플로우 방지 | 필수 |
| 문서화 | Doxygen 주석 | 권장 |

## 3. 개발 단계
1. 기능 구현
2. 단위 테스트 작성
3. 코드 리뷰 수행
4. 피드백 반영
5. 최종 검증

## 4. 예상 변경 파일
- src/xxx.c: [변경 내용]
- include/xxx.h: [변경 내용]

## 5. 검증 계획
- 빌드 검증: cargo build
- 테스트: cargo test
- 정적 분석: cargo clippy
```

**사용자 승인 요청:**
```
계획서를 검토해 주세요. 수정이 필요하거나 승인해 주시면 개발을 시작하겠습니다.
```

| **리뷰 에이전트** | 코드 검토, 피드백 제공 |

## 실행 단계 (계획 승인 후)

### Step 2: 개발 시작
개발 에이전트가 기능 구현을 시작합니다.

### Step 3: 점진적 리뷰 (병렬 진행)
개발이 진행되는 동안 리뷰 에이전트가 완성된 부분부터 검토합니다.

**리뷰 체크리스트**:

#### 🔒 안전성 (Safety)
- [ ] 버퍼 오버플로우 방지
- [ ] NULL 포인터 체크
- [ ] 정수 오버플로우 방지
- [ ] 메모리 누수 없음

#### 📏 코딩 표준 (Standards)
- [ ] MISRA-C 2023 규정 준수
- [ ] 네이밍 컨벤션 준수
- [ ] 들여쓰기 및 포맷팅
- [ ] 매직 넘버 제거

#### 📚 문서화 (Documentation)
- [ ] Doxygen 주석 완전성
- [ ] 함수 설명 (brief, param, return)
- [ ] 복잡한 로직 설명

#### ⚡ 임베디드 특화 (Embedded)
- [ ] 스택 사용량 적절
- [ ] 인터럽트 안전성
- [ ] 실시간 제약 충족
- [ ] 전력 소비 고려

### Step 4: 피드백 반영
리뷰 에이전트의 피드백을 개발 에이전트가 반영합니다.

### Step 5: 최종 검증
// turbo
모든 피드백 반영 후 최종 빌드 및 정적 분석:
```bash
# 빌드 검증
cargo build --release

# 정적 분석 (Rust)
cargo clippy -- -D warnings

# 포맷 검증
cargo fmt --check
```
